# Arov MVP Specification

## MVP Goal

Build a private full-stack app that helps the user select one appropriate next action based on current capacity, effort, impact, urgency, and mode.

## Core Features

1. Daily capacity check-in
2. Action item capture
3. Stabilize / Build / Restore classification
4. Rule-based next-small-step recommendation
5. Completion reflection
6. Basic dashboard

## Deferred

- AI planning
- Authentication
- Calendar integration
- Financial integration
- Household sharing
- Mobile app
- Notifications
- Streaks
- Productivity scoring
