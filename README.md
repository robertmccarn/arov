# Arov

Arov is a calm personal command center for reducing mental load across daily responsibilities, future-building goals, stability work, and restoration.

The first version is a single-user full-stack TypeScript app focused on one core loop:

check in → capture actions → choose one next step → complete → reflect

Arov is intentionally small at first. It is not a calendar optimizer, finance app, AI agent, or household management platform. Those may become supported pathways later, but the first goal is to prove the basic planning loop.
